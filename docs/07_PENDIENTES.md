## Uso de materiales de Facilities

Se puede reutilizar su arquitectura, secuencia de instalación, patrón de login, estructura de base, navegación y componentes visuales. No se deben copiar como criterio aprobado sus peligros, controles, permisos, MOE, bancos de preguntas o reglas de conservación. Cada elemento de Safety/Ambiental debe tener propietario, versión y aprobación KTMEX.
